# Anti-Slop Brain Vault Instructions

All paths in this file are relative to this deployed vault root, the directory
that contains this `CODEX.md`, `wiki/`, and `.raw/`.

Read order:

1. `wiki/hot.md`
2. `wiki/index.md`
3. `wiki/meta/CONVENTIONS.md`
4. Relevant workflow, source, entity, decision, or deliverable note

Rules:

- Preserve `.raw/` as immutable source material.
- Use flat YAML frontmatter and wikilinks.
- Defer note shape and confidence tags to `wiki/meta/CONVENTIONS.md`.
- Keep `hot`, `index`, `overview`, and `log` current.
- Keep recommendations source-cited.
- Do not store credentials, tokens, cookies, or private secrets.
- Do not make domain-specific claims without dated trustworthy sources.
- Apply `shipping-rules.md` before release-affecting changes.
