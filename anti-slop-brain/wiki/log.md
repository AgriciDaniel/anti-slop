## 2026-07-28, public release preparation

Licence split introduced: Apache 2.0 for code, CC BY-SA 4.0 for the
Wikipedia-derived marker taxonomies, CC BY 4.0 for original prose. The previous
state was an all-rights-reserved placeholder.

Continuous integration moved to the repository root, where it actually runs,
and extended to execute the scanner and adapter suites, the substance scorer,
and gates for long dashes, local paths, manifest validity and skill frontmatter.
