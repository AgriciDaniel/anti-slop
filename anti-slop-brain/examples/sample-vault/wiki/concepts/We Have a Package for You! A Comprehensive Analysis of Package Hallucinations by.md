# We Have a Package for You! A Comprehensive Analysis of Package Hallucinations by

## What It Says

- 19.7 percent of packages recommended by code LLMs did not exist, averaged across 16 models and 576,000 samples
- 205,474 unique hallucinated package names were observed
- Commercial models hallucinated at 5.2 percent against 21.7 percent for open-source models
- 43 percent of hallucinations recurred across all ten reruns of the same prompt and 58 percent recurred more than once
