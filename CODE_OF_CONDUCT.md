# Code of conduct

## The short version

Be straight with people. Argue with claims, not with the person making them.

## Our standards

Examples of behaviour that makes this project work:

- Bringing a source. Disagreement backed by a citation is the most useful thing
  anyone can contribute here.
- Saying "I could not verify that" rather than guessing.
- Accepting a correction without treating it as an attack. This project has
  publicly corrected itself, including a false claim in its own limitations
  note, and that is the norm rather than an embarrassment.
- Assuming a mistake is a mistake.

Examples of unacceptable behaviour:

- Personal attacks, harassment, or sustained disruption.
- Publishing someone's private information.
- Sexualised language or imagery, or unwelcome attention of any kind.
- Using this project's tooling to accuse a specific person of using AI. The
  project refuses to make authorship judgements, and using it as if it did is
  both technically wrong and a misuse of other people's work.

## A note specific to this subject

This project's own research is that style-based detection falls hardest on
English-language learners, and that human annotators show no comparable bias
where detectors do. Commentary implying that a contributor's writing "looks
like AI" is unwelcome. Review the substance: whether a claim is sourced,
whether a test is real, whether a procedure produces an artifact.

## Enforcement

Report unacceptable behaviour by opening a private security advisory, which is
the only private channel this repository has, or by contacting the maintainer
through the address on their GitHub profile.

Reports will be reviewed and investigated. The maintainer will respect the
privacy of the reporter. Maintainers who do not follow this code in good faith
may face consequences determined by other project leadership.
